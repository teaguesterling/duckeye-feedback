# duckeye feedback

Bug reports, requests and feedback for [duckeye](https://koowee.org/duckeye/), for Android and the command line.
[Open an issue](https://github.com/teaguesterling/duckeye-feedback/issues/new/choose). No GitHub account? Use the [feedback form](https://koowee.org/duckeye/feedback/#form) instead.

Issues here are public. Do not paste private content. Contact: duckeye@koowee.org.
